# 事实核查规则

`fact_check.py` 做的是**机械核查**，不判断观点对错，只保证"文章里的每个数字都能追到一句真实引文"。判断类问题（结论是否公允、语气是否合适）仍是人/LLM 的责任。

## blocking（必须修，退出码 4）

| code | 触发条件 | 修法 |
|---|---|---|
| `unsourced_number` | 正文出现带单位数字（g/mm/元/%/双/天…）但没在 claims 登记 | 补 claim，或把数字从正文删掉 |
| `no_source` | claim 没有 sources | 补来源，或删掉这条结论 |
| `source_no_url` / `source_no_quote` | 来源缺链接或缺原文引用 | 补齐；引用要含数字的那一句 |
| `quote_mismatch` | claim 的 value 在引文里找不到对应数字 | 说明这个数是编的或抄错了，回去核 |
| `insufficient_sources` | 数值类结论独立域名来源 < 2 | 找第二个独立来源，找不到就不写 |
| `conflict` | 同一 subject+metric 出现多个不同 value | 判定哪个对，或改成区间并注明各来源 |
| `out_of_range` | 重量/堆高/落差/价格超出物理合理区间 | 通常是单位换算错（oz/g、in/mm） |
| `duplicate_id` / `empty_value` | claim 结构问题 | 修数据 |

合理区间（超出即 blocking）：

| 指标 | 区间 |
|---|---|
| 重量 | 120–400 g |
| 前掌堆高 | 10–45 mm |
| 后跟堆高 | 15–55 mm |
| 落差 | 0–14 mm |
| 官方定价/发售价 | 200–3000 元 |
| 二级市场价 | 100–5000 元 |

## warning（逐条判断）

- `unsourced_bare_number`：裸数字未登记（≤12 的小数字自动放过，当序号处理）
- `absolute_claim`：出现"最强/第一/唯一/必买/稳赚/100%/吊打"等绝对化表述
- `price_source_not_dewu`：标为二级市场价但来源不是 dewu.com/poizon.com
- `source_no_date`：来源缺日期。价格类和"最新款"类必须有日期
- `missing_subject_metric`：claim 缺 subject/metric，会导致冲突检测失效

## 独立来源怎么算

按注册域名去重（`www.` 剥掉，`com.cn`/`co.uk` 正确处理）。以下**不算两个独立来源**：

- 同一站点的两个页面
- 品牌官网 + 品牌官方微信/微博（同一发布方）
- 互相转载的两条新闻（内容一致时按一个算，需人工判断）

以下算独立：品牌官方规格页 + 第三方实验室实测（RunRepeat 等）；两家独立测评媒体的各自实测。

## 常见坑

- 海外测评的重量多为男款 US9 单只，别和整双或女款混用；写文章要标注口径。
- 堆高各家测法不同（是否含鞋垫），差 1–2 mm 属正常，冲突时优先用官方 + 标注测评方。
- 得物价格是浮动的，claim 的 `date` 必须是采集当天，文章里要写"截至 X 月 X 日"。
- `--min-sources 1` 只在写"官方定价"这类单一权威来源事实时才考虑，且要在交付时说明。
